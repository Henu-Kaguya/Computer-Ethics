# 计算机伦理 课程项目要求

## 一、基本要求

1. 自由组队（3–5人），拟定题目并收集素材，撰写分析报告，制作PPT，演讲与讨论。
2. **报告内容**：自选"热门人工智能伦理话题"，针对其中伦理挑战，设计题目并收集相关素材，撰写分析报告。
3. **小组报告要求**：排版清晰、格式美观；主题明确；说明组员贡献度；≥3000字。
4. **演讲**：6月12日，5分钟演讲，现场组间互评。
5. **提交材料及时间**（6月12日提交）：
   - 分析报告
   - PPT
   - 相关素材（文字、视频等）

## 二、评分细则

### 演讲（20分）

现场组间互评，取平均分。

| 评分项   | 分值 |
| -------- | ---- |
| PPT质量  | 5分  |
| 临场效果 | 5分  |
| 演讲内容 | 10分 |

### 分析报告（30分）

| 评分项         | 分值 |
| -------------- | ---- |
| 格式           | 5分  |
| 案例描述清晰度 | 5分  |
| 伦理挑战充分性 | 8分  |
| 分析逻辑合理性 | 7分  |
| 内容充实度     | 5分  |

## 三、AI辅助使用说明

### 原则

1. **鼓励**大家利用AI工具查找资料、完善思路、优化文档。
2. **警惕**：AI智商太低，生成内容会存在明显逻辑错误和内容不客观的情况，请同学们一定注意仔细甄别，不能全盘接受AI。
3. **注意**：不用让AI把你取代了。

### 扣分规则

- 若存在明显的大量AI生成特征，得分减半（50%）。
- 若全篇AI生成，视具体情况，按 0–50% 给分。
