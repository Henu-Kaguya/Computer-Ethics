## 📝 课程大作业

- **项目主题**：AI 深度伪造 (Deepfake) 与幻觉 (Hallucination) 的伦理挑战与综合治理
- **核心内容**：
  - 深度伪造技术（换脸、拟声）对个人隐私、社会信任与信息生态的冲击
  - 大语言模型“事实幻觉”在医疗、司法、教育等高敏场景中的责任归属与伦理困境
  - 从技术防伪、行业自律、法律法规（如生成式人工智能管理办法）等多维度提出的治理对策
